# Lakshya Das — Developer Portfolio

An interactive, macOS-inspired personal developer portfolio featuring a soft pastel-blue aesthetic, Finder-style windows, a dynamic dock, and desktop applications.

Live at: [https://github.com/lakshyadas13/portfolio](https://github.com/lakshyadas13/portfolio)

---

## Features

- **macOS Desktop Interface**:
  - Top system menu bar with live clock, status indicators, and ribbon menu.
  - Translucent macOS dock with fluid hover magnification and running app indicators.
  - Finder windows with traffic light window controls (close, minimize, maximize), sidebar navigation, tag filters, search, and grid/list view toggles.

- **Desktop Folders and Projects**:
  - **ManageX**: Full-stack task management system with JWT auth, priority alerts, weekly PDF generation, and Google Calendar sync.
  - **Lovelle Scrapbook**: A pastel-themed digital memory scrapbook web app built with Next.js, Tailwind CSS, and Supabase.
  - **Personal Portfolio**: The interactive macOS desktop portfolio itself.

- **Native Resume.pdf Viewer**:
  - Embedded in-app PDF document previewer that renders directly inside a macOS-style window without external redirects.
  - Quick action buttons for direct PDF download and Google Drive viewing.

- **Soft Pastel-Blue Aesthetic**:
  - Elegant powder blue (`#A8C9F5`) and cool deep navy (`#1e3a68`) color scheme.
  - Dynamic desktop wallpapers (dots, lace, gingham, blush).
  - Ribbon ties, micro-animations, and clean desktop design elements.

- **Built-in System Applications**:
  - **TextEdit (About Me)**: Bio, quick links to CV, GitHub, LinkedIn, and email.
  - **Mail (Contact)**: Functional email composer with pre-filled mailto triggers and one-click address copy.
  - **Calendar (Availability)**: Real-time availability indicator.
  - **Messages (FAQ)**: Interactive chatbot answering questions about tech stack and projects.
  - **Notes (Now)**: Live status list of current pursuits and opportunities.
  - **Music Box**: Ribbon waltz 8-bit synthesizer with sound generation.
  - **Skills Window**: Visual grid of programming languages and technologies.
  - **Gallery**: Visual project card previewer.

## Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 6](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Design System**: [shadcn/ui](https://ui.shadcn.com/) tokens and CSS variables
- **Icons and Graphics**: Custom vector SVGs, Lucide icons

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/lakshyadas13/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to explore the desktop.

### Build for Production

```bash
npm run build
```
